# 蓝破碎半圆

`蓝破碎半圆` 是 ZENINEXU 的笔记及博客。

在破碎信息里，留下判断的现场。

线上阅读：https://zenine.github.io/lanposui-blog/

## 我们写什么

这个博客关注 AI 时代的技术、产品、工程和行业判断，核心视角来自医疗垂直深度、大模型应用架构和工程化交付。

这里不追逐更响的观点，而是记录问题发生时的依据、边界、选择和代价：当信息不完整、约束会变化、答案并不唯一时，一个技术时代的参与者如何判断，如何修正，如何承担结果。

目前主要写这些方向：

- AI 与工程实践
- 技术决策与产品判断
- 医疗信息化和医疗 AI 观察
- 写作、职业和长期系统积累
- 元认知、概念和问题边界

## 关于 ZENINEXU

ZENINEXU 是一名长期在医疗健康 AI、医疗大数据和企业级医疗产品交付一线工作的技术架构者。

过往工作横跨数据分析、深度学习算法、AI 产品 0 到 1、研发协同、标准 / 专利 / 课题建设和集团级 AI 产品化推进。更关心的不是单点技术炫技，而是怎样把模型、数据、产品、流程和安全边界组合成能被真实业务使用的系统。

这个博客保存的是一线判断的底稿：不是教程，也不是结论展览，而是把当时知道什么、不知道什么、为什么这样选、什么证据会改变判断写下来。
